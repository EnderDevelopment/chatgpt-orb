# ChatGPT Orb

ChatGPT Orb is a lightweight Minecraft mod that adds a floating orb and a chat screen to your game. The orb is a small, floating white sphere with a glowing cyan symbol that follows the player smoothly. Press the 'O' key to open an in-game chat screen. This mod is designed to be lightweight and focuses on providing a basic chat interface and a visual orb.

## Install

1. Download the mod file from the GitHub repository.
2. Place the downloaded file in the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Forge mod loader installed.

## Use

1. Launch Minecraft with the mod installed.
2. In-game, press the 'O' key to toggle the orb on or off.
3. To open the chat screen, press the 'O' key again when the orb is active.
